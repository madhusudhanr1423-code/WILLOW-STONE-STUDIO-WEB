# Willow & Stone Studio

A full-stack booking platform for managing services, appointments, and users — built with a real admin dashboard, authentication, and a live database, not just a static front end.

🔗 **Live demo:** https://willow-stone-studio-web-vkay.vercel.app/

## Tech Stack
- React + TypeScript
- Supabase (database + auth)
- Tailwind CSS
- Vite

## Features
- User authentication and account management
- Admin dashboard for managing services and appointments
- Live database-backed booking system
- Fully responsive design
